# S284 — Un agent qui relit les promesses : « jamais », « aucun », « parce que » *(epic E27, persona : Léa)*

## Objectif

Léa peut croire ce que l'application lui promet (« vos coordonnées ne sont
envoyées à personne », « hors connexion, toutes les fiches restent
consultables ») : un agent relit chaque promesse écrite — à l'écran, dans un
commentaire, dans la doc — et dit laquelle le code ne tient pas.

## Pourquoi maintenant

- Repris de Sentiers (`.claude/agents/relecteur-de-promesses.md`),
  inventaire du 18/10 (`docs/DEPOTS-FRERES.md`).
- CLAUDE.md §4bis (« un commentaire qui justifie une existence est une
  affirmation ») et §5 (« ce qu'on affirme, on l'a vérifié ») n'ont aucun
  outil : seule la revue adverse les applique, au fil d'un diff, jamais sur
  ce qui est déjà écrit.
