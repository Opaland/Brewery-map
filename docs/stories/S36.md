# S36 — Une note personnelle par brasserie *(epic E3, persona : Bernard)*

## Objectif

Dans la fiche, Bernard écrit une note pour lui seul (« la blanche était
excellente », « fermé le lundi en vrai »). Elle reste sur son appareil, et
la fiche la montre à sa prochaine visite.

## Critères d'acceptation

| # | Critère | Prouvé par |
|---|---|---|
| CA1 | Les notes sont gardées comme `{ nom, texte }` ; au plus 500 caractères, coupées au relu ; une note illisible tombe seule | `tests/unit/preferences.test.ts` |
| CA2 | La fiche a un champ « Ma note (sur cet appareil seulement) » ; la note est gardée sans bouton, à la saisie, et relue au retour | `tests/e2e/carnet.spec.ts` |
| CA3 | Une note vidée est retirée du stockage | `tests/unit/preferences.test.ts` |
| CA4 | La note ne part jamais : ni dans le signalement prérempli, ni dans le partage d'une fiche | `tests/unit/signalement.test.ts`, `tests/unit/partage.test.ts` (aucun champ « note perso » lu) ; relecture |
| CA5 | « Tout effacer » efface les notes, et le texte de stockage le dit | `tests/e2e/carnet.spec.ts` |

## Hors périmètre

Recherche dans les notes ; notes sur la carte.
