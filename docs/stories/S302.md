# S302 — La porte tourne sous Windows et PowerShell *(revue globale du 19/10, W1 à W4, plus W6 à W8 ; personas : Cédric, la contributrice externe)*

## Objectif

Cédric, sur son PC fixe sous Windows, et une contributrice qui clone le
dépôt sous Windows, lancent la porte complète et la voient verte sur un
arbre sain. Le crochet avant commit la lance vraiment, sans Git Bash
ni `jq` à installer pour qu'il garde quelque chose.

## Pourquoi maintenant

Revue globale du 19/10 (`docs/REVUE-GLOBALE-2026-10-19.md`, groupe W) :
« W1 à W4, avant tout travail sur le PC fixe ». Mesuré le 19/10 sur ce
poste (Windows 11, PowerShell 5.1, Node 24.13, Git 2.45, clone par défaut,
donc `core.autocrlf=true`) :

| Commande | Résultat |
|---|---|
| `npm run lint` | 1 erreur : `src/MiseAJour.tsx` « was not found by the project service » |
| `npx tsc -b --noEmit` | 3 erreurs : `MiseAJour.ts` et `miseAJour.ts` « differ only in casing » |
| `npx vitest run` | 13 échecs sur 646 : 4 de fins de ligne (W1), 8 d'`outil-curation` (W3), 1 de `lien-externe` |
| `npm run build` | échoue sur `tsc -b` |
| `npx playwright test` | aucun test lancé : `dist` n'existe pas |

Après une ré-extraction en LF (`core.autocrlf=false`), il reste 9 échecs
Vitest : les 8 de W3 et celui de `lien-externe`. La porte rougissait aussi
sur deux constats que la revue n'avait pas vus, ajoutés ici :

- **W6**. `src/MiseAJour.tsx` (le composant) et `src/miseAJour.ts` (la
  logique) ne diffèrent que par la casse. Windows ne distingue pas les
  majuscules des minuscules, et TypeScript essaie `.ts` avant `.tsx`. Donc
  `import { MiseAJour } from './MiseAJour'` (`src/App.tsx:50`) ouvre
  `miseAJour.ts`. Ce seul défaut fait rougir lint, tsc, build et e2e.
- **W7**. `tests/unit/lien-externe.test.ts:20` compare des chemins à
  `'src/Carte.tsx'`, et `join` rend `src\Carte.tsx` sous Windows : le test
  croit que `Carte.tsx` et `LienExterne.tsx` posent `_blank` à la main.

- **W8** (vu en lançant la porte complète). `vite preview` de Sentiers, un
  dépôt frère, tenait déjà le port par défaut de Vite, 4173. Hors CI,
  Playwright réutilise un serveur déjà lancé (`reuseExistingServer`) : il a
  testé Sentiers, et 209 e2e sur 222 ont rougi pour cette seule raison.

Pour W2, `jq` n'était pas installé sur ce poste : les trois crochets lisent
la commande par `jq … || echo ""`. Sans `jq`, la commande lue est vide, et
`porte-avant-commit.sh` sort en 0 sans rien lancer. La porte avant commit ne
gardait rien, et sans rien dire.
