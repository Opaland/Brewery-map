# S378 — Sous Firefox, ouvrir une fiche ne fait plus déborder la page *(issue #250, persona : Inès)*

## Objectif

Une personne qui lit à 200 % sous Firefox, sur un téléphone, ouvre une fiche sans devoir défiler de côté.

## Pourquoi maintenant

Les rouges de Firefox (#250), lus le 31/10 : à 320 et 412 px, texte à 200 %, la page monte à 491 px dès qu'une fiche s'ouvre. Mesuré : le champ « Ma note » impose sa largeur naturelle dans sa grille (`.champ`). Ni le tableau des horaires ni le texte réservé au lecteur d'écran n'y sont pour rien : les corriger, essai fait, ne change pas la mesure.
