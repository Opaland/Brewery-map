# S369 — La porte tourne sous Windows sans le mode développeur *(epic E29, persona : la contributrice externe)*

## Objectif

Une contributrice sous Windows peut passer la porte sans activer le mode développeur.

## Pourquoi maintenant

Vu le 30/10 en reprenant S345 sur le PC fixe : les deux tests de liens symboliques de S360 (`tests/unit/workflows.test.ts`) échouent en EPERM, ce qui bloque le crochet avant commit. Ils ont été écrits en session cloud, sous Linux.

## Critères d'acceptation

| # | Étant donné… quand… alors… | Prouvé par |
|---|---|---|
| CA1 | Sous Windows sans mode développeur, `npx vitest run tests/unit/workflows.test.ts` est vert, les deux tests comptés comme sautés | commande locale (vu rouge avant le correctif) |
| CA2 | Sous Linux, les deux tests jouent toujours : la garde reste tenue en CI | le job `porte` : `ci.yml` tourne sur ubuntu, et `skipIf` ne porte que sur `win32` |

## Hors périmètre

La garde elle-même, qui ne s'exécute qu'en CI.

## Décisions de Cédric requises

Aucune.

## Porte qualité

**PASSE** quand le job `porte` est vert.
