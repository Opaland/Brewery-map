# S270 — Les brasseries de Bretagne entrent sur la carte *(epic E26, persona : Cédric)*

## Objectif

Cédric voit sur la carte les 81 brasseries de Bretagne que les lots
départementaux ont trouvées (Côtes-d'Armor, Finistère, Ille-et-Vilaine,
Morbihan), chacune avec sa catégorie, ses sources et une position qui dit
ce qu'elle vaut.

## Pourquoi maintenant

- Cédric, le 18/10 : les fiches nouvelles des lots départementaux, « toutes,
  avec leur catégorie », une PR par région (`docs/DECISIONS.md`).
- `curation/dep-22`, `29`, `35`, `56` : 81 fiches (22, 19, 17, 23) ; 38 à
  l'adresse, 43 au centre IGN de leur commune, écrites `commune` avant S269.
- S269 a outillé le chemin : `outils/centres-ajouts.ts`, `centreRelu`,
  `retirerCeQuiADesFiches`.
