# S45 — Thème clair, sombre ou automatique *(epic E10, persona : Inès)*

## Objectif

Inès choisit l'apparence de l'application : comme son téléphone, claire ou
sombre. Le choix est gardé sur l'appareil.

## Critères d'acceptation

| # | Critère | Prouvé par |
|---|---|---|
| CA1 | « Sombre » assombrit un téléphone réglé en clair ; « Claire » éclaircit un téléphone réglé en sombre ; « Comme le téléphone » rend la main au système | `tests/e2e/theme.spec.ts` (rouge sans le plugin) |
| CA2 | Le choix se garde au retour, posé avant le premier rendu | même fichier ; `tests/unit/preferences.test.ts` |
| CA3 | Une seule source de couleurs sombres : le plugin tire les règles forcées des blocs `prefers-color-scheme: dark`, et un bloc qu'il ne sait pas lire fait échouer le build | `tests/unit/theme.test.ts` |

## Décisions de Cédric requises

Aucune.
