# S382 — Appeler le numéro que cite la source *(hors plan, backlog autonome ; persona : Hugo)*

> Écrite avant le code par le backlog autonome du 25/11
> (`docs/BACKLOG-AUTONOME.md`), sur l'issue #288, point 2.

## Objectif

Quand le seul numéro d'une brasserie est cité dans la note, Hugo peut
l'appeler d'un toucher depuis la partie « Joindre la brasserie », au lieu de
le recopier.

## Pourquoi maintenant

Issue #288, point 2 (persona Marie, 12/11). Le cas est revenu à chaque
campagne depuis, chaque fois que le numéro est écrit dans une forme que
`controler` ne relit pas : « +33 », points, chiffres collés. Il passe alors
dans la note :
- Tarnon (48, 23/11) ;
- La Méridienne (65, 23/11) ;
- La Canya (66, 24/11) ;
- Oxit (81, 25/11).

La persona Hugo l'a relevé deux fois. Aujourd'hui, `Contact.tsx` dit « La
source cite un numéro, non revérifié : voyez « Ce que dit la source », plus
haut. ». Or le titre « Ce que dit la source » n'existe pas sur une fiche en
catégorie 0 : c'est le point 2 de #292.

## Critères d'acceptation

| # | Étant donné… quand… alors… | Prouvé par |
|---|---|---|
| CA1 | Une note qui cite « 04 66 48 03 68 », « 06.70.07.73.61 » ou « 0625690895 » : `numerosCites` rend ces numéros, écrits « 04 66 48 03 68 » ; `citeUnNumero` reste vrai exactement quand la liste n'est pas vide. | `tests/unit/contact.test.ts` (vu rouge : fonction absente, puis motif sans les points) |
| CA2 | Une note qui cite un nombre de dix chiffres sans 0 en tête, ou un code postal suivi d'autres chiffres, ne rend aucun numéro. | `tests/unit/contact.test.ts` |
| CA3 | Une fiche sans `contact.tel` dont la note cite un numéro : la partie « Joindre » montre un lien « Appeler le 04 66 48 03 68 (numéro cité par la source, non revérifié) » vers `tel:+33466480368`. Le renvoi à « Ce que dit la source, plus haut » disparaît. | `tests/composants/contact.test.tsx` et `tests/unit/contact-rendu.test.ts` (vus rouges : ancien texte, aucun lien) |
| CA4 | Une fiche qui a un `contact.tel` : rien ne change, et le numéro de la note n'est pas proposé en plus. | `tests/composants/contact.test.tsx` |
| CA5 | Le texte anglais existe pour la nouvelle formule ; l'ancienne a disparu de toutes les surfaces (`grep`). | `tests/unit/i18n.test.ts` |

## Hors périmètre

- Le libellé « Acheter seulement » (#288, point 1) : décision de Cédric.
- Les numéros en « +33 » dans une note : aucune note de `data/` n'en porte
  aujourd'hui (les lots les réécrivent en « 04 … »). Ils restent non cliquables.
- Lire ces formes dans `controler` pour les mettre dans `contact.tel` : cela
  toucherait des données.
- Le reste de #292 : la phrase de confiance, la correction chez l'office.
- Reprendre dans le libellé du lien ce que la note dit de la ligne (ventes pro, office) : à Cédric.

## Décisions de Cédric requises

Aucune. La story ne change aucune donnée. Elle rend cliquable un numéro que
la fiche affiche déjà, et dit toujours qu'il n'est pas revérifié.

## Porte qualité

Verdict : PASSE.

- Tests vus rouges sans le correctif : `numerosCites` absente, l'ancien texte, puis le doublon et le 08 (revue adverse).
- Revue adverse :
  - un numéro écrit deux fois donnait deux liens et une clé React en double : dédoublonné, test ajouté ;
  - un 08 devenait un lien « Appeler » : exclu par la règle de `contact.tel`, désormais partagée (`TELEPHONE_APPELABLE`, §4ter) ;
  - `citeUnNumero` est inchangé sur les 941 notes.
- Persona Hugo : les 17 fiches composent le bon numéro.
  - Brasserie Baudille cite la ligne des ventes pro, et Tarnon et Oppidum un numéro lu sur l'office.
  - Le lien dit « cité par la source, non revérifié », et la note qui précise l'origine est juste au-dessus.
  - Changer le libellé selon la qualification de la note : laissé à une décision de Cédric (#288).
