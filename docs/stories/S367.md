# S367 — Le premier écran avant 600 fiches, mesuré *(epic E36 ; persona : Bernard)*

## Objectif

Bernard, sur son téléphone ancien, voit la première ligne de la liste aussi
vite qu'avant, alors que la carte passe 600 fiches avec les régions
suivantes (S344 et après).

## Pourquoi maintenant

`docs/PREMIER-ECRAN.md`, « Règle de réévaluation » : « Avant chaque lot qui
porte le fichier au-delà de 600 fiches […], la mesure se refait avec la même
commande ». `data/` compte 557 fiches (S365-S366) ; S344 (Hauts-de-France)
le portera au-delà.

## Critères d'acceptation

| # | Étant donné… quand… alors… | Prouvé par |

| CA1 | Le premier écran est mesuré sur le fichier réel (557 fiches) par `outils/mesure-premier-ecran.ts`, 5 essais : LCP, première ligne, octets, écart entre essais. | tableau ajouté à `docs/PREMIER-ECRAN.md` |
| CA2 | Le même outil mesure un fichier synthétique de 1 000 fiches dont les lignes ajoutées sont hors Auvergne-Rhône-Alpes (dupliquées, renommées, dans une copie jetable jamais publiée) : on sait si le premier écran grossit avec les autres régions. | même tableau ; `poids.spec.ts` sur la copie |
