# S244 — Le registre SIRENE contre OpenStreetMap, sur trois départements *(epic E25)*

## Objectif

Savoir si le registre national des entreprises (code d'activité 11.05Z,
« Fabrication de bière ») trouve des brasseries qu'OpenStreetMap ignore, et
l'inverse, avant de bâtir la découverte de la France entière dessus.

## Pourquoi maintenant

Cédric, 17/10 : « Coutances, aucune fiche renseignée ». La couche OSM a
8 brasseries dans la Manche ; on ne sait pas combien il en manque.

## Démarche

- Source : l'API publique de recherche d'entreprises de l'État
  (recherche-entreprises.api.gouv.fr), sans compte, établissements actifs
  au code 11.05Z.
- Départements témoins : Manche (50, le pilote), Rhône (69, le mieux connu
  du fichier), Finistère (29, le plus dense de la couche OSM).
- Rapprochement par commune et nom (sans accents, mots génériques retirés),
  relu à la main sur la Manche.

## Critères d'acceptation

| # | Étant donné… quand… alors… | Prouvé par |
|---|---|---|
| CA1 | Pour chaque département : nombre SIRENE, nombre OSM, communs, propres à chacun | `docs/SIRENE.md` |
| CA2 | Les limites dites : une entreprise 11.05Z n'est pas forcément un lieu ouvert au public, une brasserie peut être déclarée sous un autre code | `docs/SIRENE.md` |
| CA3 | Une recommandation pour S246 (quelle source pour la découverte) | `docs/SIRENE.md` |

## Ce que la story ne fait pas

Aucune ligne de `data/`, aucune fiche proposée : une mesure.
