# S40 — Une brasserie choisie dans un groupe, signalée *(epic E2, persona : Hugo)*

## Objectif

Quand la brasserie choisie est dans un groupe de marqueurs, Hugo voit
lequel, et le lecteur d'écran le dit.

## Pourquoi maintenant

Revue adverse S2 (BACKLOG) : une brasserie choisie dans un groupe n'a aucun
retour visuel sur la carte.

## Critères d'acceptation

| # | Critère | Prouvé par |
|---|---|---|
| CA1 | Le groupe qui contient la brasserie choisie porte un anneau (classe `contient-choisie`) | `tests/e2e/carte-depart.spec.ts` |
| CA2 | Son nom accessible dit « dont « X », choisie » | même test |
| CA3 | Refermée, plus aucun groupe n'est marqué | même test |

Aucune.
