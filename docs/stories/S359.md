# S359 — Les constantes dites deux fois, tenues d'accord *(issue #211, persona : la contributrice externe)*

## Objectif

Celle qui lit `docs/ARCHITECTURE.md`, `docs/PORTE.md`, le README ou
`CONTRIBUTING.md` y trouve les valeurs que le code applique : une constante
changée d'un seul côté fait rougir un test, et le motif d'un département
n'est écrit qu'une fois.

## Pourquoi maintenant

Revue globale du 22/10 (issue #211, agents `chasseur-de-jumeaux`,
`relecteur-de-promesses`, `relecteur-de-workflows`, `contributrice-externe`).
Les paires sont d'accord aujourd'hui, mais rien ne les tient (§4ter).
