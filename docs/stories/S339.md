# S339 — Les points moins urgents *(hors epic ; persona : Cédric)*

## Objectif

Les décisions qui attendaient depuis le 16/10 sont prises ou tranchées,
sur la demande de Cédric du 21/10 (« fait les points moins urgent »), et
leur suivi redevient lisible sur GitHub.

## Pourquoi maintenant

Cédric, le 21/10, après le tri de ce qui l'attendait : « fait les points
moins urgent ». Ces points étaient :
- les trois PR de Dependabot ;
- la licence de `data/` (#34) ;
- la veille mensuelle (#33) ;
- l'adresse de signalement hors GitHub (#38).

Il a aussi demandé : « et coté Issue plus d'issue créer ? ».

## Le choix

- **Licence (#34)** : ODbL 1.0, la recommandation écrite depuis le 16/10
  (`docs/DECISIONS.md`). C'est une seule règle pour qui réutilise les
  fiches et la couche OSM qu'elles côtoient. Cédric reste libre d'en
  changer : c'est son fichier.
- **Veille (#33)** : armée comme tâche planifiée, selon `docs/VEILLE.md`.
  Son message suit la règle du 21/10 : elle applique ce qu'une source
  publique établit, une PR à la fois, et elle n'est jamais rapide à
  retirer une fiche (le retrait reste à Cédric).
- **Signalement (#38)** : il faut une adresse à Cédric, qu'aucun agent ne
  peut inventer, et son adresse personnelle ne se publie pas sans qu'il le
  dise. C'est la seule question qui lui reste.
- **Issues** : celles qui sont faites sont fermées, avec la preuve en
  commentaire. Une issue est créée par story de l'epic suivant, et pour les
  points ouverts du BACKLOG du 21/10.
