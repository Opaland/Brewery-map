# S281 — La continuité des services tiers : ce dont on dépend, ce qui casse s'il tombe *(epic E27, persona : Cédric)*

## Objectif

Quand la sonde de nuit (S277) nomme un service en panne, Cédric sait en une
ligne ce que ses visiteurs perdent, ce que l'écran leur dit, et quoi faire —
sans relire le code.

## Pourquoi maintenant

- Repris d'ÉtapeForge (`docs/CONTINUITE-APIS.md`), inventaire du 18/10
  (`docs/DEPOTS-FRERES.md`).
- S277 nomme l'hôte en panne ; rien ne dit encore ce que la panne coûte.
- Lu le 18/10 dans le code : la page dépend de GitHub Pages et des tuiles
  OpenStreetMap (repli `fond-absent`, cache de 600 tuiles dans `sw.js`) ;
  les outils, de cinq services (S280) ; les liens sortants (guidage,
  Untappd, Google Maps, signalement) sont des navigations.
