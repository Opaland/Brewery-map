# S52 — Proposer une position *(priorité de Cédric, 17/10)*

## Objectif

Cédric : « la localisation des brasseries ne correspond pas à l'adresse sur
la carte ». Les 166 fiches ont une position communale (S59 : pas des centres, `docs/PRECISION.md`) ; aucune
procédure ne permettait de les déplacer (revue code S11 : `km` resterait
périmé). Un lot peut désormais proposer une position.

## Critères d'acceptation

| # | Critère | Prouvé par |
|---|---|---|
| CA1 | Une position se propose entière (`lat`, `lon`, `coordPrecision`), jamais vers le centre de la commune ; une coordonnée seule est refusée | `tests/unit/curation.test.ts` (vus rouges avant le code) |
| CA2 | `km` est recalculé depuis Brignais, arrondi au dixième | même fichier |
| CA3 | Une position seule ne date pas la fiche | même fichier |
| CA4 | Le diff dit de combien la fiche bouge | même fichier |

## Hors périmètre
