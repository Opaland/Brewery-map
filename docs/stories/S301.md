# S301 — Dire quel filtre cache un favori *(issue #53 ; personas : Marie, Inès)*

## Objectif

Marie voit pourquoi un de ses favoris n'est pas dans la liste (trop loin,
une catégorie décochée, un type de bière, le texte cherché, déjà visité),
même quand elle n'a pas coché « seulement mes favoris ».

## Pourquoi maintenant

Revue Marie S9, `BACKLOG.md`, issue #53 :
- la phrase « caché par la distance ou les filtres » ne dit pas lequel ;
- hors du mode « seulement », un favori hors du rayon n'est pas signalé du
  tout : Marie croit qu'il a disparu.

## Décision de présentation (§2) : pas de second bouton dans la ligne

L'issue demande de trancher l'étoile-bouton dans la ligne, avec Inès. Ce
qui se compte : chaque ligne est aujourd'hui **un** arrêt au clavier (le
bouton qui déplie la fiche). Un bouton favori par ligne en ferait **deux** :
2 × N arrêts pour N lignes. Le bouton « Ajouter à mes favoris » reste dans
la fiche dépliée, à un geste de la ligne. L'étoile de la ligne reste une
marque, pas un bouton. Écartées : un bouton dans la ligne (le coût clavier
d'Inès) ; un raccourci clavier (rien ne le montre à l'écran).

## Hors périmètre

- Un bouton favori dans la ligne (décision ci-dessus).
- Dire la raison d'une fiche non favorite qui manque.
