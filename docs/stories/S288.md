# S288 — Deux angles de revue de plus : les workflows CI, le contributeur externe *(epic E27, persona : Cédric)*

## Objectif

Cédric sait si ses workflows peuvent être détournés (droits, secrets,
actions tierces, texte d'une PR injecté dans une commande) et si une
personne extérieure peut cloner le dépôt, lancer la porte et proposer une
correction sans lui demander comment.

## Pourquoi maintenant

- Repris d'ÉtapeForge (`.claude/agents/revue-personas.md`), inventaire du
  18/10 (`docs/DEPOTS-FRERES.md`).
- Quatre workflows (`ci.yml`, `mutation.yml`, `visuel-references.yml`,
  `sonde-nuit.yml`), dont un qui pousse un commit (`visuel-references`) :
  aucune revue ne les lit sous l'angle d'un attaquant.
- Pas de `CONTRIBUTING.md` (lu le 18/10) ; le signalement d'une erreur de
  fiche existe (S10), pas le chemin d'une contribution de code.

Aucune pour les angles ; un réglage du dépôt, s'il en sort un, lui revient.
