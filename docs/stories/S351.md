## Objectif

Les dépendances npm reçoivent leurs mises à jour mineures et leurs
correctifs par une seule PR par mois. Les réponses de Cédric du 22/10 sont
écrites là où une reprise les lit.

signalait les failles, sans rien proposer. Cédric a choisi, le 22/10,
« Mensuel, groupé, sans majeures ».

accepte bien la configuration ne se voit qu'après le merge, sur la page
Dependabot du dépôt : ce n'est pas prouvé par cette PR (§5).
