# S279 — La liste à dérouler sur un vrai téléphone avant une livraison *(epic E27, persona : Cédric)* **[H]**

## Objectif

Cédric, avant d'annoncer une version, déroule en un quart d'heure sur son
téléphone ce qu'aucun test automatique ne peut constater, et note ce qu'il
a vu — plutôt que de découvrir après coup qu'un geste ne marche que dans
l'émulation.

## Pourquoi maintenant

- Repris de Sentiers (`docs/RELEASE.md`), inventaire du 18/10
  (`docs/DEPOTS-FRERES.md`).
- `BACKLOG.md` et la revue S22 (`docs/SPRINTS.md`) : « rien n'est essayé
  sur un vrai téléphone (installation réelle, permission « demander à
  chaque fois », délais du GPS) ». `src/main.tsx` renvoie lui-même à « un
  vrai iPhone » pour `:active` (S234).
- Ce que l'émulation ne fait pas, relevé dans le code le 18/10 : la fenêtre
  d'installation (`beforeinstallprompt`), les raccourcis de l'icône
  (`manifest.webmanifest`), la feuille de partage (`navigator.share`),
  l'ouverture d'une appli de guidage, le sélecteur de fichier, l'impression,
  la fenêtre de permission de Firefox pour `storage.persist` (S275).
