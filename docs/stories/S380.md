## Objectif

Cédric peut faire écrire par Claude, à la demande, un court texte « ce qui a
changé ce mois-ci sur la carte », dont chaque nombre et chaque nom de
brasserie viennent des données, et qui lui arrive comme une proposition
qu'il accepte ou refuse.

## Pourquoi maintenant

L'étude de Netatmo (10/11) : Netatmo fait écrire son analyse du mois par
Claude, mais calcule tous les chiffres lui-même et refuse un texte qui en
inventerait (`collector/insights.py`, `unknown_numbers`). Chez nous, la règle
« aucune donnée inventée » (AGENTS.md §0) impose la même garde, plus une sur
les noms de brasseries.

## Le choix d'architecture

- **Claude n'est jamais appelé depuis la page** : elle est statique (GitHub
  Pages) et une clé dans le JavaScript serait lisible par tous. L'appel se
  fait dans un outil (`outils/mot-du-mois.ts`), lancé à la main ou par un
  workflow à la demande ; la clé `ANTHROPIC_API_KEY` est un secret du dépôt.
- **Le code calcule les faits, Claude écrit le texte** (`src/core/mot-du-mois.ts`,
  fonctions pures). Le texte est refusé s'il contient un nombre ou un nom de
  brasserie absent des faits ; une seule réécriture est demandée, avec la
  liste des écarts ; si elle échoue encore, le texte est gardé avec
  `verifie: false` et le dit.
- **Le résultat est une proposition** : `curation/ia/mot-du-mois-AAAA-MM.json`,
  ouvert en PR. Rien n'entre dans `data/` ni dans l'écran par cette story.

## Porte qualité

Verdict : PASSE (code), en attente de Cédric pour le premier passage réel
(la clé).

Revue adverse du 11/11, six trouvailles vérifiées, toutes traitées :
1. `faitsDuMois` plantait sur les vraies données (78 fiches sans
   `verifieLe`) : champ optionnel, test sur `data/breweries.json`.
2. Lint rouge : corrigé.
3. Tout compte de 1 à 31 passait : les jours ne sont plus permis qu'à
   l'intérieur d'une date (« le 1er novembre », « les 10 et 11 novembre ») ;
   les codes de département et les dates des faits ne légitiment plus un
   compte.
4. « 1.5 » et « 12.31 » lus en morceaux : le point décimal est lu.
5. Les noms : sans casse ni accents, en mot entier (« Banz » n'est pas dans
   « Banzaï »), et un nom contenu dans un nom permis cité n'est pas un écart.
6. La PR ouverte par GitHub Actions ne lance pas la CI : dit dans le
   workflow et dans le corps de la PR (la fermer puis la rouvrir).
Points mineurs traités : `npm ci --ignore-scripts` dans le job qui a le
jeton d'écriture ; le job sans clé recalcule les faits depuis le dépôt et
revérifie le texte au lieu de croire le champ `verifie` (test vu rouge).

Limites écrites : les nombres en lettres (« dix ») et les noms absents de
`data/` (une commune, une marque) ne sont pas détectés ; la consigne les
interdit, et Cédric relit avant toute publication. Le coût affiché est une
estimation (prix lus le 11/11), pas un plafond : le plafond se pose sur la
console Anthropic.
