## Décision prise au jugé (§2 : présentation, pas calcul)

**Pas de dossier `.github/ISSUE_TEMPLATE/`.** La doc de GitHub dit que les
paramètres d'URL « peuvent aussi être passés au sélecteur de gabarits »
(*Creating an issue from a URL query*, lu le 27/10). Avec des gabarits, les
liens préremplis de l'application (`/issues/new?title=…&body=…`, « Signaler
une erreur », « La signaler ») risqueraient donc de passer par ce sélecteur
au lieu d'ouvrir l'issue préremplie : un geste de plus pour Marie ou
Bernard, que je ne peux pas vérifier sans compte. Le gabarit vit dans
`CONTRIBUTING.md`, à copier. Piste écartée, et pourquoi : le dossier de
gabarits. Le test le tient (aucun `ISSUE_TEMPLATE`), avec cette raison dans
son message.
