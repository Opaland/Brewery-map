## Décision prise au jugé (§2 : présentation, pas calcul)

**Pas de dossier `.github/ISSUE_TEMPLATE/`.** La doc de GitHub
(*Creating an issue from a URL query*, lue le 27/10) dit que « Query
parameters for issue form fields can also be passed to the issue template
chooser » : elle parle des champs des formulaires YAML, et ne dit pas ce que
deviennent `title` et `body` quand le dépôt a des gabarits Markdown.
Les liens préremplis de l'application (`/issues/new?title=…&body=…`,
« Signaler une erreur », « La signaler ») pourraient donc passer par le
sélecteur au lieu d'ouvrir l'issue préremplie, un geste de plus pour Marie
ou Bernard. C'est une prudence, pas un fait mesuré : sans compte GitHub, je
ne peux pas le vérifier. Le gabarit vit donc dans `CONTRIBUTING.md`, à
copier. La piste écartée est le dossier de gabarits, réversible si Cédric
l'essaie avec son compte. Le test le tient (aucun `ISSUE_TEMPLATE`), et son
message renvoie ici.
