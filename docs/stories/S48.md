# S48 — Interface en anglais (1/3) : le socle *(epic E10, persona : une visiteuse étrangère)*

## Objectif

Poser de quoi traduire l'interface sans risquer une page à moitié anglaise :
un dictionnaire, une fonction `t()`, une garde qui exige chaque traduction,
et les textes de l'écran principal (`App.tsx`).

## Critères d'acceptation

| # | Critère | Prouvé par |
|---|---|---|
| CA1 | Chaque appel `t('…')` du code a sa traduction anglaise ; aucune traduction orpheline ; mêmes paramètres dans les deux langues | `tests/unit/i18n.test.ts` (vu rouge : 67 clés manquantes avant le dictionnaire) |
| CA2 | La langue est la première du navigateur que l'on sait parler ; l'anglais reste éteint tant que tous les écrans ne sont pas traduits (`ANGLAIS_PRET`) | même fichier |
| CA3 | Les tests de bout en bout tournent en français (`locale: 'fr-FR'`), quelle que soit la langue du profil d'appareil | `playwright.config.ts` |
| CA4 | Rien ne change pour un visiteur francophone | la porte entière, inchangée |

## Hors périmètre

Les autres composants (S49), les textes de `src/core` et l'allumage (S50).
Les fiches restent en français : ce sont des citations de leurs sources.

public (touristes, randonneurs, frontaliers) : c'était au plan v4.
